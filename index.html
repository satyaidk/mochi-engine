How to flash

Follow these steps before starting the installer.

1

Connect

Connect the ESP32-C3 Dev Module to your computer using a USB data cable.

2

Open the installer

Click the Flash Mochi Firmware button and select the ESP32-C3 serial port.

3

Flash

Allow ESP Web Tools to erase and write the firmware. Do not disconnect USB during flashing.

Important

Flashing firmware can erase data stored on the device. Use a reliable USB data cable and keep the device connected until ESP Web Tools reports that installation has completed.

Troubleshooting

Common problems and fixes.

Device not detected

Try another USB cable, USB port, or put the ESP32-C3 into bootloader mode manually.

Manifest download failed

Open manifest.json directly in the browser and verify that the firmware paths match the repository structure.

Flashing fails

Disconnect other serial applications, close Arduino Serial Monitor, and retry with the board in bootloader mode.

GitHub Pages 404

Verify that index.html is located in the selected Pages publishing directory and that Pages is enabled.

Old firmware appears

Hard refresh the browser and verify that the published manifest and BIN files are the latest versions.

S3 troubleshooting

This installer targets ESP32-C3. An ESP32-S3 requires a manifest build specifically targeting ESP32-S3.
