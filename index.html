How to install

Watch the video tutorial
  1. 一

    Plug in the board

    Connect the Super Mini to your computer with a USB-C cable that carries data. Charge-only cables won't show up.

  2. 二

    Click Install Mochi

    Your browser lists the serial ports it can see. Pick the one named USB JTAG/serial debug unit and connect.

  3. 三

    Wait for it to finish

    The installer erases the board and writes Mochi. Keep the cable plugged in until it says installation is complete.

  4. 四

    Say hello

    Mochi restarts and its face appears. Once it's on your Wi-Fi, open mochi.local to change faces, sounds and the clock.

!

Installing can erase what's saved on the board, like its Wi-Fi details. If the cable comes loose midway, the board may not start; run the installer again to fix it.

If something goes wrong

Most problems come down to the cable or another app holding the port. Start there.

The board isn't in the port list

Try a different cable or USB port. If it still doesn't appear, put the board into download mode: hold BOOT, press and release RST, then let go of BOOT. Click Install Mochi again.

Installing stops partway

Close the Arduino Serial Monitor and any other app using the port, put the board into download mode, and try again.

No face on the screen after installing

Mochi looks for the screen at I²C address 0x3C or 0x3D. Check the SDA and SCL wires. If you used different pins, set them in the controller at mochi.local.

The installer says the chip isn't supported

This build is for ESP32-C3 boards only. An ESP32-S3 needs its own S3 build of the firmware.

If you host this installer

GitHub Pages shows a 404

Check that index.html sits in the folder Pages publishes from, and that Pages is turned on for the repository.

The firmware files won't download

Open manifest.json in the browser and check that every firmware path in it matches a file in the repository.

An old version still installs

Hard refresh the page, then confirm the published manifest.json and .bin files are the latest ones.
